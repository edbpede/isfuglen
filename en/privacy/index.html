Privacy

What the tool stores, where it lives, and how to delete it.

In short

The tool runs entirely in your browser. There is no server, no account, no database and no analytics. Your text never leaves this computer.

What is stored, and where

Language choice and settings
Stored in the browser's localStorage under the keys nl.uiLang,nl.docLang and nl.settings.
The newsletter you are working on
Saved automatically in the browser's IndexedDB under nl.current, so you do not lose work by accident.
Named drafts
Stored in the same place under nl.draft.<id>.

All of it lives on this computer, in this browser profile. Nothing is sent anywhere.

It is not encrypted

Drafts are stored in your browser on this computer. They are not encrypted and are not suitable for highly confidential information. Anyone with access to this computer and this browser profile can read them.Do not use this tool for individual member cases or health information.

How to delete everything

Open Drafts in the newsletter window and chooseDelete all stored data. That clears both settings and drafts and reloads the page. There are no other copies.

How long does it stay?

Until you delete it — with three exceptions the browser decides, not us:

  • Safari deletes all stored data after seven days without using the site.
  • Private windows delete everything when the last window closes.
  • Some school-managed browsers clear site data on sign-out.

That is why Download all drafts as a file exists. The downloaded file is the only durable backup, and it lives wherever you save it.

What the tool never does

  • Send your text to a server. There is none.
  • Use cookies to recognise you.
  • Load fonts, scripts or images from another domain.
  • Measure your behaviour or send error reports.
  • Use artificial intelligence or translation services.

The site sets a Content Security Policy that permits connections to the site itself only, and the automated test fails on so much as one network request to another domain during a full paste-edit-export cycle.
