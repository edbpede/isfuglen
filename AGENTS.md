# AGENTS.md

This file provides guidance to AI coding agents when working with code in this
repository.

A browser-only newsletter generator: paste Danish/English meeting notes, get a
laid-out A4 newsletter with PDF/DOCX/clipboard export. Astro 7 + Svelte 5
islands + UnoCSS on Bun.

## Commands

Bun is the runtime, installer, script runner and test runner. `npm`/`pnpm`/`npx`
in `package.json`, `bunfig.toml`, `scripts/` or a workflow is blocked by a prek
hook — use `bun`, `bunx --bun`.

| Task | Command |
| --- | --- |
| Dev server | `bun run dev` |
| Build | `bun run build` (runs `build:assets` first) |
| Typecheck | `bun run check` — `astro check` + `svelte-check`; plain `tsc` sees neither `.astro` nor `.svelte` |
| Format + lint | `bun run format` (`biome check --write .`) |
| Unit tests | `bun test` — scoped to `tests/unit` by `bunfig.toml` |
| One unit file | `bun test tests/unit/parser/dates.test.ts` |
| One unit case | `bun test tests/unit/parser/dates.test.ts -t "partial name"` |
| E2E | `bun run test:e2e` — Playwright builds and serves `dist/` itself |
| One E2E file | `bunx --bun playwright test tests/e2e/core-flow.spec.ts -g "partial name"` |
| Bundle budget | `bun run check:bundle` |

On a clean checkout run `bun run build:assets` before `bun test`:
`tests/unit/export/docx.test.ts` and `tests/unit/export/fonts.test.ts` read
generated artefacts that are gitignored.

## Generated files — never hand-edit

Both are gitignored and rebuilt by `bun run build:assets`:

- `public/brand/*@300.png` — `scripts/build-logo-png.ts`
- `public/fonts/pdf/` — `scripts/build-pdf-fonts.ts` (static TTF instances
  decoded out of the Fontsource packages; the PDF writer cannot embed variable
  fonts)

## Invariants

**`docs/PLAN.md` does not exist.** Roughly 85 comments across 30 files cite it by
section number (`§6.4`, `§16.3`, …). It was deleted; the citations were not. Do
not go looking for it and do not treat a missing section as unwritten — the
comment around the citation is the surviving spec.

**Two language systems, deliberately unmergeable.**
`src/lib/i18n/` holds interface messages, resolved from `$uiLang`
(localStorage, `src/lib/storage/prefs.ts`). `src/lib/labels/` holds the words
the *template* prints inside the newsletter, resolved from the document's own
`docLang`. `src/lib/export/` and `src/lib/render/` import `labels/` and, for
`Intl` only, `i18n/format.ts` — never the message catalogs. Every `Intl` call in
the project goes through `src/lib/i18n/format.ts` (Danish uses `15.30`, and
Æ Ø Å collate after Z).

**Palette lives in two files and must agree.** `palette` in `uno.config.ts` and
the custom properties in `src/styles/tokens.css`. Change both;
`tests/unit/styles/tokens.test.ts` fails otherwise. `--c-accent` (gold) is a
rule/chip/notice fill only — never text, icon or focus ring.

**Runtime styling must go through the CSSOM.** The CSP is generated by
`security.csp` in `astro.config.mjs` and hash-locks scripts, so
`setAttribute("style", …)` and a `<style>` element built in JS are both refused.
Use `element.style.prop` or `CSSStyleSheet`/`adoptedStyleSheets` — see
`src/lib/export/paint.ts` and the Paged.js polisher redirect in
`src/lib/export/pdf.ts`.

**The initial workspace chunk has a 160 KB gz budget.** `manualChunks` in
`astro.config.mjs` names `pagedjs`, `libpdf`, `docx`, `editor`, `schema`, and
`scripts/check-bundle.ts` also requires `paint` and `write` to stay separate.
Reach these only through `await import(...)`; a static import from the workspace
path collapses the chunk and fails `bun run check:bundle`.

**No server.** `output: "static"`, no adapter, no SSR, no middleware, no API
route — the absence is a product guarantee, and `tests/e2e/privacy.spec.ts`
asserts no request leaves the app's own assets.

**Zod runs only at the storage boundary** (`src/lib/model/schema.ts`). Nothing
on the parse/render path validates. A schema change needs a step in
`steps` in `src/lib/model/migrate.ts`, keyed by the version it migrates *from*.

**Routes are translated, not prefixed.** `src/lib/i18n/routes.ts` is the only
place that knows the mapping (`/hjaelp` ↔ `/en/help`). A new page means a file
in `src/pages/` *and* `src/pages/en/`, plus an entry there;
`.github/workflows/smoke.yml` probes all eight published paths.

**Brand SVG drop-in contract:** `<path>` elements only, no `transform`, no
elliptical arcs. `src/lib/export/svg-path.ts` refuses anything else by name.

## Stack rules enforced by prek

`prek.toml` makes these unpushable rather than merely discouraged, so a failure
here is a config statement, not a style opinion:

- Svelte 5 runes only — no `export let`, `on:click`, `$:`
- `client:only` must name its framework (`client:only="svelte"`)
- No `Astro.glob(` (removed in Astro 7)
- `uno.config.ts` uses `presetWind4`; `presetUno`/`presetWind3` are rejected
- No class names assembled at runtime. UnoCSS only generates what it can scan —
  use full literal class strings picked by a lookup map (see
  `src/lib/render/html.ts`) or the `safelist` in `uno.config.ts`
- Conventional Commits at `commit-msg`; no direct commits to `main`

Hooks only fire after `prek install`. CI runs them via
`prek run --all-files --hook-stage manual`.

Biome is the only formatter and linter, and it does **not** format `.astro` or
`.svelte` (it lints their script blocks and sorts imports) and has no Markdown
support. Format template markup by hand.

## Layout

- `src/lib/parser/` — text → `NewsletterDoc`. Entry `parseNewsletter` in
  `index.ts`; stages are `normalise → segment → classify → group → header →
  assemble → repair → report`. Language-specific cues in `rules/da.ts`,
  `rules/en.ts`.
- `src/lib/render/html.ts` — the single renderer for the on-screen preview, the
  printed page and the Paged.js source. "Preview matches export" holds because
  there is one function, not two.
- `src/styles/document.css` — the newsletter's whole appearance, plain CSS
  rather than utility classes. `print.css` is authored to be correct on its own
  so a Paged.js failure degrades instead of breaking.
- `src/islands/` — Svelte 5 islands; the workspace is one `client:load` island.
  `src/lib/stores/*.svelte.ts` are runes classes; `src/lib/storage/prefs.ts` is
  nanostores/localStorage (synchronous, so first paint has the right language),
  `documents.ts` is IndexedDB.
